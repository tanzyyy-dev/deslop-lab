# STEP2 改善計画（統括エージェント）

- 作成: 2026-11-21 / Claude Opus 5.5（統括）
- 入力: STEP1 の成果物（`steps/step-01`）と、その評価（`records/step-01/meta.json` の evaluation）、調査メモ（`docs/research/ai-slop.md`）

## 1. 方針

調査では、フォントや色を一つ差し替えるだけでは解決しないことが繰り返し指摘されていた（Capital & Compute）。また、既定値を禁止すると、モデルは次の既定値に移るだけだとも言われている。そこで次の順に進める。

1. **何を伝えるサイトか**（情報設計・コピー）を先に直す。見た目の改善は、中身が決まってからでないと「別の既定値への着せ替え」になる。
2. 次に、キャラクター固有の世界観（下記のデザイン方針）から**書体 → 色 → レイアウト → 画像**の順に決める。
3. 最後に、アクセシビリティ、性能、細部を詰める。

一度に全部を直さず、観点ごとに1ステップとする。各ステップの前後差分が、教材として読み取れる大きさになるようにするため。

## 2. ステップ構成

| STEP | 観点（チェックリスト） | 主な作業 |
|---|---|---|
| 2-1 | 情報設計（C2）＋明らかな不具合 | セクションの優先順位を見直す（次の予定と最新情報を上に）。カウントダウンをやめて日付・会場を直接示す。情報のない帯を削除。ナビゲーションの日本語化。NEWS のずれを修正。 |
| 2-2 | コピー（C3） | ルミ本人／運営の声で書き直す。仮の英単語と矛盾を解消する。デモフォームを、実際に機能する導線に置き換える。 |
| 2-3 | タイポグラフィ（C4） | 書体を選び、サイズの階層をつけ、日本語の組版を整える。重複している英字の小見出しを整理する。 |
| 2-4 | 色と装飾・モーション（C5, C7） | 役割を持ったパレットに置き換える。グラデーション文字、発光、常時アニメーションをやめる。 |
| 2-5 | レイアウトとリズム（C6） | 同一カードの反復をやめ、内容に応じた形（番組表、ディスコグラフィの一覧、主役の1枚）にする。ヒーローの構図を見直す。 |
| 2-6 | 画像（C8） | ジャケット画像を同じ世界観で生成する。別人に見えるステージ画像を差し替える。画像を軽量化する。 |
| 2-7 | アクセシビリティと仕上げ（C9, C10） | コントラスト、フォーカス、タップ領域、メタ情報、favicon、細部の確認。 |

各ステップのあとで3画面幅のスクリーンショットを撮り、統括がレビューする。意図どおりでなければ再指示し、その内容も記録する。全ステップを終えた時点で、全体をもう一度チェックリストで評価する。必要ならステップを追加する。

## 3. デザイン方針（STEP 2-3 以降で使う）

STEP1 で AI 自身が作った設定から、デザインに反映されていなかった個性を拾い上げて軸にする。新しい設定は足さない。

- 使う設定: 深夜ラジオ番組「ルミの夜更かし電波」、星空観測、雨の日のプラネタリウム巡り、ラムネ色の夕焼けが好き、停電が苦手（光でできているから）、作曲は本人。
- **コンセプト: 「夜更かしの周波数」**。深夜ラジオの番組表と星図。ネオンの都市ではなく、夜更かしする部屋の静かな灯りに寄せる。ファンへの距離感は、手紙やラジオへの投稿のように近い。
- 色（役割で決める。グラデーションは写真以外で使わない）:
  - 夜（背景）: 深い藍。純粋な黒は使わない
  - 文字: 少し青みのある白／補助文字はコントラスト 4.5:1 以上を確保する
  - ラムネ（唯一のブランドアクセント）: 淡いラムネ色。リンク、現在地、主要ボタン
  - 灯（状態色）: 暖かいランプの黄色。「ON AIR」「次の予定」など、今を示す場所にだけ使う
- 書体: 見出しは丸みのある日本語書体（アイドルの声のやわらかさ）、本文は読みやすいゴシック、日付・時刻・周波数だけはドット書体（ラジオの表示窓）。いずれも Google Fonts（OFL）。
- モーション: 原則なし。ホバーとフォーカスの状態変化だけにする。
- 文脈上の判断: 暗い背景は「深夜」という設定から選んだもの。AI Slop の兆候としての「暗背景＋ネオン」とは区別し、発光と多色グラデーションを取り除いたうえで残す。
