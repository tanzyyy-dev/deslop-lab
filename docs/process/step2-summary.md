## 3. 観察（教材として伝えたいこと）

- **STEP1 は「技術的には正しかった」**。axe-core の自動監査では、STEP1 に違反はひとつもなかった。AI Slop の問題は、壊れていることではない。誰も選んでいない既定値で埋まっていることにある（Built In の言う「technically correct」）。
- **改善の途中で、新しい問題が入り込んだ**。2-1 で実装エージェントが加えた半透明（opacity .7）は、2-4 の配色変更と重なって「終了」ラベルのコントラスト不足を生んだ。2-4 で下線を外したフッターのリンクは、色だけで区別される状態になった。2-2 の負の margin は、2-3 で注記のずれとして表面化した（統括は 2-2 のレビューで見落としていた）。一度に1観点ずつ直し、毎回3画面幅で確かめることで、原因のステップを特定できた。
- **Haiku 5.5 は、具体的な指示には正確に従った**。指示が曖昧な箇所では、上位のルール（「設定にない事実を作らない」）を優先して判断した。反面、「見た目で確かめる」ことはほとんどしなかった。崩れは、毎回統括のスクリーンショット確認で見つかった。
- **「暗い背景」は残した**。調査では「暗背景＋ネオン」が AI Slop の兆候として挙がっていた。しかしこのサイトでは、暗い背景は設定の「深夜」から選べる表現だった。取り除いたのは、選ばれていない部分（発光と多色グラデーション）だけである。

## 4. 残存課題（STEP3 で人間に判断を仰ぎたい点）

1. **プロフィール画像**: STEP1 の画像を、キャラクターの基準として残した。後光と発光する線の描写があり、ほかの画像よりネオン寄りに見える。新しい画像に差し替えるかどうか。
2. **キャラクター設定の「電脳都市ネオ・ミナト」「光合成ラボ」**: STEP1 の AI が作った設定で、言葉としては残している。新しい世界観（静かな夜の部屋）と完全には重ならない。
3. **書体の読み込み**: Google Fonts（外部 CDN）を使っている。読み込めない環境では、システムフォントで表示される。自前で配信するかどうか（日本語フォントは容量が大きい）。
4. **OGP 画像**: 相対パスのまま。GitHub Pages で公開する URL が決まったら、絶対 URL にする必要がある。
5. **英語の固有名**（Holiday Stream Special、Fan Meeting「Good Night, Lumi」、Starlight Tシャツ）: STEP1 の命名を固有名として残した。
6. **アイドルとしての華やかさ**: 静けさを優先した結果、「アイドルのサイトらしい楽しさ」が弱まっていないか。これは人間の感覚で判断してほしい点。
