## ニュースのずれの原因
CSS の `.section-alt > * { margin-left: auto; margin-right: auto; max-width: var(--max) }` で、見出し（.section-head）は 1100px の中央寄せになります。しかし `.news-list { margin: 0; ... }` がこの指定を後から打ち消し、リストだけ左端（セクションの padding 位置）に張り付いていました。デスクトップ幅（1100px 超）で見出しとリストの左端がずれ、900px 以下では両方とも左端なので差が見えませんでした。
修正: `.news-list` の `margin: 0` を `margin: 0 auto` に変更。HTML 側の変更は不要でした。
