## 背景
サイトのコンセプトは「夜更かしの周波数」です。深夜ラジオ番組を持ち、星を眺め、自分で曲を作るAIアイドルの、静かで親密な夜をイメージしています。
ところが現在の配色は、シアン・紫・ピンクの3色を均等に使っています。名前はグラデーション文字で、ボタンはグラデーションのうえ発光しています。背景には発光する円がいくつも置かれ、星が流れ続け、画像は浮遊し、スクロール誘導も動いています。これは「暗い背景にネオン」という、AI製サイトによくある既定の見た目です。コンセプトの静けさとも合っていません。
暗い背景は「深夜」という設定から選んだものなので、残します。取り除くのは、発光、多色のグラデーション、常に動き続けるアニメーションです。

## 新しいパレット（役割で使い分ける）
css/style.css の :root を次の値に置き換えてください。--cyan / --pink / --violet / --accent-grad は削除します。これらを使っている箇所は、下の役割に従ってすべて置き換えてください。
```css
--bg: #111830;        /* 夜。ページの背景 */
--bg-2: #18213f;      /* 交互のセクション背景 */
--surface: #1b2547;   /* カードや囲みの面（半透明の白をやめて不透明にする） */
--line: rgba(238, 241, 248, 0.14);
--text: #eef1f8;      /* 本文 */
--text-sub: #b3bcd3;  /* 補足文（背景とのコントラスト 9:1） */
--text-muted: #8b95b0;/* さらに控えめな情報（5.8:1） */
--ramune: #8fdcd3;    /* 唯一のブランドアクセント。リンク、主ボタン、フォーカス */
--ramune-strong: #b0e9e2; /* 主ボタンのホバー */
--lamp: #ffcf6b;      /* 状態色。「次のライブ」「残りわずか」など、今を示す場所だけ */
--on-accent: #111830; /* ラムネ色・灯色の上に置く文字 */
```
（コントラスト比はすべて WCAG AA を満たすことを統括側で計算済みです。）

## 役割ごとの指定
- 名前「天音ルミ」: グラデーション文字をやめ、単色の --text にする（background-clip: text などを削除）
- リンク: --ramune。ホバーで下線を出す
- 主ボタン: 背景 --ramune、文字 --on-accent、影なし、グラデーションなし。ホバーでは背景を --ramune-strong にするだけ（位置を動かさない）
- 副ボタン: 背景なし、1px の --line の枠、文字 --text。ホバーで枠を --ramune にする
- ヒーローの「次のライブ」の囲み: 背景 --surface、左だけの色付き線をやめて、1px の --line の枠にする。ラベル「次のライブ」の文字色を --lamp にする（このサイトで --lamp を使う代表的な場所）
- スケジュールの種別ラベル（配信／ラジオ／ライブ）: 色分けした塗りのピルをやめ、1px の --line の枠と --text-sub の文字にする。「終了」は --text-muted の文字
- ニュースの日付: --text-sub
- プロフィール表の項目名（dt）: --text-sub
- プロフィールの引用文: 左のピンクの線をやめる。代わりに Zen Maru Gothic（--font-display）の 500、1.25rem で、--text の色にする
- プロフィール画像の背景の紫の円形グラデーション: 単色 --bg-2 にする
- 在庫表示: 在庫あり → --text-sub、残りわずか → --lamp、売り切れ → --text-muted
- ロゴのマーク（.logo-mark）: グラデーションをやめ、背景 --ramune、文字 --on-accent
- 楽曲のジャケットとグッズの仮画像: グラデーションと text-shadow の発光をやめ、背景 --bg-2、1px の --line の枠にする。番号（01 など）は --text-muted。画像は後のステップで用意するので、今は落ち着いた仮の面にしておく
- カードの背景: 半透明の白（--panel）をやめ、--surface にする
- フォーカス表示: 2px solid var(--ramune)、outline-offset 3px（a, button など全体で統一）
- テキスト選択色（::selection）: 背景 --ramune、文字 --on-accent

## 取り除くもの
- ヘッダーのすりガラス（backdrop-filter）。背景は不透明な --bg、下に 1px の --line
- ヒーロー背景の発光する円（radial-gradient）。ヒーローの背景は --bg の単色
- 星の点の背景と、その drift アニメーション（@keyframes drift も削除）
- ヒーロー画像の float アニメーション（@keyframes float も削除）
- スクロール誘導（.scroll-cue の a 要素を HTML から削除し、CSS と @keyframes cue も削除）
- ボタンやカードのホバー時の transform（浮き上がり）と発光する box-shadow
- transition は color / background-color / border-color だけを 0.15s で変化させる（transform や box-shadow を transition の対象にしない）。ただしモバイルメニューのハンバーガーの開閉アニメーションは残してよい
