## 1. スケジュールの時刻が大きくなる問題
- 原因: `.schedule time { display: block; font-size: 1.125rem; ... }` が、日付の列の <time> だけでなく、説明文の中の <time> にも当たっていました（display: block で改行され、同じ大きさになる）。
- 修正: セレクタを `.schedule > li > time` に限定しました（日付の列の <time> は li の直下にあります）。
- 確認（Chrome、1366px など）: 説明文内の時刻は inline・15px（説明文と同じ大きさ、同じ行）。日付は 18px のままです。

## 2. PC ヒーローの紹介文が幕の切れ目にかかる問題
- 修正（PC・1024px 以上）: `.hero-visual::after` の linear-gradient を、左端から 40% まで不透明度 0.92、70% で 0 にしました（指示どおり）。
- 修正（721〜1023px）: 文字の列が画面の幅に占める割合が大きいため、目安の値では足りず、このブレークポイントだけ「60% まで 0.92、95% で 0」に伸ばしました。
- 確認: 文字の列（max-width 520px）の右端は、1366px で 47%、1023px で 56%、820px で 68%、721px で 77% の位置です。721px のスクリーンショットでは、紹介文が暗い部分に収まって読めることを目視確認しました。

## 迷った点・意図どおりにできなかった点
- 1366px では、文字の列の右端（47%）が 40% の地点を少し超えています。そこでの不透明度は約 0.7 で、スクリーンショットでは読めますが、「40% までは 0.92」の目安を文字列全体では完全には満たしていません。
- 820px では、列の右端（68%）で不透明度が約 0.7 です。スクリーンショットは撮っていません（721px と 1366px で確認）。
- 720px 以下は、画像が上に分離しているので、この幕は使いません（非表示）。
