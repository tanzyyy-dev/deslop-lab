## 作業
1. 共通の幅
   - :root に --gutter: clamp(16px, 5vw, 48px); と --max: 1120px; を定義し、すべてのセクションの内容を同じ規則（max-width: var(--max)、左右に var(--gutter) の余白、中央寄せ）でそろえてください。.section と .section-alt の違いは背景色だけにします。PC幅で、すべてのセクションの見出しの左端が同じ x 座標になることを確認してください。
   - 角丸は --radius: 8px に下げてください。ジャケット画像とグッズ画像は角丸を 2px にします（CDジャケットや商品写真は四角いもの）。ピル型（999px）はスケジュールの種別ラベルだけに残します。

2. ヒーロー（画像が主役の構図にする）
   - PC・タブレット幅（721px 以上）: ヒーローをページの全幅にします。画像（images/hero.png）を、ヒーロー全体を覆う背景として配置してください（img 要素のまま、position: absolute; inset: 0; width/height: 100%; object-fit: cover; object-position: 70% center）。文字は左側に重ねます。画像の左側だけに、文字を読みやすくするための暗い幕を重ねてください（::after で、--bg から透明へ向かう横方向の linear-gradient。不透明度は左端 0.92 → 中央付近 0）。これは装飾ではなく、可読性のための幕です。ヒーローの高さは min-height: min(88svh, 820px)、文字の列は max-width 520px 程度。ヒーロー内の要素の左端は、ほかのセクションと同じ var(--gutter) と --max の規則でそろえます。
   - スマホ幅（720px 以下）: 画像を上に置き（幅100%、aspect-ratio 4 / 3、object-fit: cover、object-position: 72% center）、その下に文字を置きます。画像の上に文字を重ねないでください。文字は左揃えにします（現在の中央揃えをやめる）。
   - .hero-bg 要素は不要になるので削除してください。

3. スケジュールとニュース（「最新の情報」として1つのまとまりにする）
   - PC幅（1024px 以上）では、スケジュールとニュースを同じセクション背景の中で横に並べます（スケジュール 7 : ニュース 5 程度の2段組、間隔 64px 程度）。id="schedule" と id="news" は、それぞれの見出しを含む要素に残し、ナビゲーションからのリンクが機能するようにしてください。1023px 以下では縦に並べます。
   - 2つの見出し（h2）は、この並びの中では少し小さくしてかまいません（clamp(1.5rem, 3vw, 2rem) 程度）。
   - スケジュールの日付は 1.125rem に大きくし、番組表のように日付の列を強くします。

4. 楽曲（最新作を主役に、ほかは一覧に）
   - 最新作の「LUMINA」（1stアルバム）を先頭に大きく表示します。PC幅ではジャケット（左、幅 44% 程度）と文字（右）の2段組にし、カードの枠は付けません。
   - 2枚のシングル（Midnight Signal、Lumen Drop の順。新しい順）は、その下に横長の行として並べます。各行は、ジャケット（96px の正方形）と、タイトル・種別と日付・コメントを左右に並べ、行の間に 1px の --line の区切り線を入れます。カードの枠は付けません。
   - スマホ幅では、最新作のジャケットを幅100%、その下に文字。シングルの行は、ジャケット 72px のまま横並びにします。
   - 「試聴・配信のリンクは準備中です。」は、最新作の文字の下か、セクション見出しのすぐ下に置きます（負の margin は使わないこと）。

5. プロフィール
   - 現在の2段組を維持します。画像の列を少し狭くし（grid-template-columns: 5fr 7fr 程度）、画像の角丸は --radius にします。

6. グッズ（商品の一覧として軽くする）

7. ファンレター

8. 余白のリズム

   - 見出しと内容の間は 32〜40px、関連する要素どうしは 8〜16px、別の話題は 48px 以上と、近さで関係が分かるようにしてください。
