## 背景
統括エージェントが、axe-core（WCAG 2.2 の A / AA 規則）と独自のチェックでこのサイトを監査しました。結果は records/step-08/audit-before.json にあります（読み取り専用）。主な指摘は次のとおりです。
- 「終了」ラベル（.tag-past）のコントラスト不足。原因は、終了した予定の行全体にかかっている opacity: .7
- フッターの「ページの先頭へ」リンクが、色だけで本文と区別されている。タップ領域も高さ 20px しかない
- スキップリンク、favicon、OGP、theme-color がない
また、コードを読んで次の問題も見つかっています。
- スマホ幅で閉じているメニューのリンクに、Tab キーでフォーカスが移ってしまう（見えないのに操作できる）
- メニューを Esc キーで閉じられない
- スケジュールの見出し構造: グループ名（今後の予定／終了した予定）と、各予定の名前が、どちらも h3 になっている

## 作業
1. コントラスト
   - .schedule-past li の opacity を削除してください。終了した予定は、文字色を --text-muted（背景とのコントラスト 5.8:1）にすることで控えめに見せます。日付・予定名・説明・ラベルのすべてが、WCAG AA（通常の文字 4.5:1）を満たすようにします。
2. リンクとタップ領域
   - フッターの「ページの先頭へ」に下線を付け、上下に余白を足してタップ領域を高さ 44px 以上にしてください。
   - 本文中のリンク（ニュースの各項目、「詳細はスケジュールへ」など）は、ホバー時だけでなく常に下線か、色以外の手がかりで区別できるようにしてください（ニュースの項目は行全体がリンクなので、下線は不要です。ただし、ホバーとフォーカスで背景色か下線が出るようにします）。
3. スキップリンク
   - body の最初に「本文へスキップ」リンク（href="#main"）を置き、<main id="main"> にしてください。通常は画面外に隠し、フォーカスされたときだけ左上に表示します（背景 --ramune、文字 --on-accent）。
4. モバイルメニュー（js/main.js と CSS）
   - スマホ幅でメニューが閉じているときは、リンクにフォーカスが移らないようにしてください（例: 閉じているときは visibility: hidden。開くときは visible に戻す）。
   - メニューが開いているとき、Esc キーで閉じて、フォーカスをメニューボタンに戻してください。
   - 画面幅が広がって PC 表示に切り替わったときに、メニューが開いたままの状態が残らないようにしてください。
5. 見出し構造
   - スケジュールの各予定の名前を h4 にしてください（グループ名の h3 の下に入るため）。見た目（文字の大きさ・太さ）は今と同じに保ちます。
6. メタ情報と favicon
   - favicon を SVG で作ってください（images/favicon.svg）。デザインは、角丸の正方形（背景 #8fdcd3）に、Zen Maru Gothic 風の太い「ル」の字ではなく、シンプルな図形にしてください。ラジオの電波を表す同心円弧3本（色 #111830）が目安です。文字を使わないのは、フォントが読み込まれない環境でも同じ形に見えるようにするためです。
   - <link rel="icon" href="images/favicon.svg" type="image/svg+xml"> を追加してください。
   - <meta name="theme-color" content="#111830"> を追加してください。
   - OGP を追加してください: og:type=website、og:title（title と同じ）、og:description（meta description と同じ）、og:image=images/hero-night.webp、og:locale=ja_JP。
7. 細部
   - プロフィールの「登録上の誕生日は 2 月 14 日」の半角スペースを削除し、「2月14日」にしてください（ほかの日付表記とそろえる）。
   - html の scroll-behavior: smooth は、prefers-reduced-motion: reduce のときに auto になっていることを確認してください（すでにあれば変更不要）。
