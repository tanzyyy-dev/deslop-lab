これは架空のAIアイドル「天音ルミ」の公式サイトです。STEP3 では、人間のレビュアーの指示をもとに修正します。

## レビュアーの指示
楽曲紹介欄で、実際に曲を試聴できるようにしたい。オーディオの部品を入れる。ブラウザ標準のままの簡素な部品にはせず、サイト全体と統一感のあるデザインにする。

## 素材
レビュアーが用意した音源を、統括エージェントが steps/step-10/audio/ にコピー済みです。
- audio/midnight-signal.mp3 … 「Midnight Signal」（2ndシングル）、長さ 2:57
- audio/lumen-drop.mp3 … 「Lumen Drop」（1stシングル）、長さ 2:29
アルバム「LUMINA」の音源はありません。

## デザインの方針（統一感のために守ること）
このサイトのコンセプトは「夜更かしの周波数」（深夜ラジオ、星空、静かな部屋の灯り）です。プレーヤーも、この世界観の部品として作ってください。
- **色**: 既存の CSS 変数だけを使う。新しい色の値は作らない
  - 再生ボタン: 主ボタンと同じ考え方（背景 --ramune、アイコン --on-accent）。ホバーで --ramune-strong
  - 「今、鳴っている」ことを示す状態色は --lamp。再生中の曲にだけ使う（このサイトで --lamp は「今」を示す色として使っている）
  - 線・枠は --line、補足の文字は --text-sub / --text-muted
- **書体**: 経過時間と曲の長さ（例「1:05 / 2:57」）は、日付・時刻と同じドット書体（--font-dot）にする。ラジオの表示窓のように見せるため。ラベルは本文書体
- **形**: 角丸は既存の --radius（8px）。再生ボタンは円形。グラデーション、発光（box-shadow の光）、すりガラスは使わない
- **シークバー**: input[type="range"] をスタイルし直して使う。細い線（高さ 4px 程度）で、再生済みの部分は --ramune、未再生の部分は --line。つまみは小さな円。ラジオの周波数の目盛りのように、バーの下に細い目盛り線を入れてもよい（任意。入れる場合は控えめに）
- **動き**: 再生中であることを示す小さな表示（例: --lamp の小さな丸と「再生中」の文字）を出す。点滅や波形のアニメーションは使わない（このサイトは常時アニメーションを使わない方針のため）
- **大きさ**: 再生ボタンとシークバーのつまみは、タップしやすい大きさ（ボタンは 44px 四方以上）にする

## 構成
1. 各シングルの行（.release-row）の .release-text の中、コメントの下に、プレーヤーを1つずつ置く。
   - 再生／一時停止ボタン（アイコンは SVG。再生は三角、一時停止は2本線）
   - シークバー
   - 時間表示「経過 / 長さ」
   - 再生中の表示
2. アルバム「LUMINA」には、プレーヤーを置かない。
3. セクション見出しの下の「試聴・配信のリンクは準備中です。」を、「シングル2曲を試聴できます。アルバム『LUMINA』の試聴は準備中です。」に変更する。
4. HTML には、まず `<audio controls preload="metadata" src="audio/….mp3">` を置く。JavaScript が動く環境では、それを独自のプレーヤーの UI に置き換える（標準の controls を外し、独自の UI を表示する）。JavaScript が動かない環境でも、標準の audio 部品で試聴できるようにするため（段階的な強化）。
5. JavaScript（js/main.js に追加するか、js/player.js を新しく作って読み込む）で、次を実装する。
   - 再生／一時停止の切り替え。ボタンの aria-label を「Midnight Signal を再生」「Midnight Signal を一時停止」のように、状態と曲名に合わせて切り替える。aria-pressed は使わない
   - 1曲を再生したら、ほかの曲は一時停止する（同時に2曲鳴らない）
   - シークバー: 再生位置に追従させ、ドラッグ・タップ・キーボード（← → で5秒、Home / End）で位置を変えられるようにする。aria-valuetext を「1分05秒 / 2分57秒」のように読み上げやすい形にする
   - 時間表示: メタデータを読み込んだら長さを表示する。読み込むまでは「--:-- / --:--」
   - 状態: 読み込み中（バッファ待ち）は「読み込み中…」、再生できなかった場合は「再生できませんでした」と表示する（エラー状態を作ること）
   - 曲が最後まで再生されたら、先頭に戻して停止状態にする
   - Media Session API（navigator.mediaSession）に対応しているブラウザでは、曲名・アーティスト名「天音ルミ」・ジャケット画像を設定する。スマホのロック画面などに表示されるようにするため
6. 再生中の行は、見た目でも分かるようにする（例: 行の曲名の横に --lamp の丸）。ただし行全体の背景色を変えるなど、目立たせすぎない。
