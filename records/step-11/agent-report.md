## 迷った点・意図どおりにできなかった点
- **D のキーボードフォーカス**: 商品カードにフォーカス可能な要素がない（商品名は h3）ため、hover のみで実装。指示書の「なければ hover のみでよい」に従った。
- **E の安全策**: AudioContext と createMediaElementSource は、演出がオンのとき、再生ボタンのクリック（ユーザー操作）の中でだけ作る。file:// では使わない（cross-origin 扱いで無音になるおそれがあるため）。AudioContext が running でないときは経路につながない。経路につないだ後は analyser を必ず destination に接続している。ただし実機で音が出ることは未確認なので、http で開いて音を確認してほしい。
- **E の一時停止中の表示**: 指示どおり、一度メーターが動いた後は一時停止中も最小高さの棒を残す（「●」には戻さない）。演出オフのときだけ「●」に戻る。
- **A の名前の読み上げ**: 名前の分割は JS ではなく HTML に直接書いた（ちらつきを避けるため）。h1 の aria-label で「天音ルミ」と読まれる。`.en`（LUMI AMANE）も A に合わせてフェードさせた（指示書の順序に含まれていなかったための追加）。
- **切り替えボタンの reduced-motion**: 指示書の「reduced-motion では全部止める」を優先し、ボタンは disabled にした。
