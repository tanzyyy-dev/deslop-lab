これは架空のAIアイドル「天音ルミ」の公式サイトです。STEP3 では、人間のレビュアーの指示をもとに修正します。

## レビュアーの指示
現状は、静かで落ち着いた雰囲気の静的サイトとして仕上がっている。派手にならない匙加減は必要だが、AIアイドルのサイトであることをイメージして、華やかさ・可愛らしさ・視覚効果を取り入れたい。

## 動きの方針（統括エージェントが決めたルール。必ず守ること）
1. **動きにはすべて意味を持たせる**。サイトのコンセプト「夜更かしの周波数」から、使ってよいモチーフは次の3つだけです。どの動きも、このどれかを表すものにします。
   - 電波のチューニング（ノイズから声がはっきりする、周波数が合う）
   - 星のまたたき（星図、流れ星、きらめき）
   - ホログラムの光（ルミは「光でできたAIアイドル」。ホログラムのグッズがある）
2. **一律の演出はしない**。全セクションのフェードアップ、全画像のホバー拡大、バウンスするイージングは使いません（これらは AI 製サイトの典型的な既定値として、STEP2 で取り除いたものです）。演出は、以下で指定した場所にだけ入れます。
3. **色は既存の変数だけ**（--ramune、--lamp、--text など）。新しい色の値は作りません。
4. **アクセシビリティ**
   - `prefers-reduced-motion: reduce` のときは、すべての演出を止め、最終状態をすぐに表示します。
   - 5秒以上続く動き（星のまたたきなど）には、止める手段を用意します（WCAG 2.2.2）。具体的には下の「演出の切り替え」を作ります。
   - 演出のための要素（canvas など）は aria-hidden="true" にし、文字の読み取りや操作の邪魔をしないこと（pointer-events: none）。
5. **性能**: アニメーションは transform と opacity、または canvas で行います。canvas は requestAnimationFrame で描き、画面外にあるとき（IntersectionObserver）とタブが非表示のとき（visibilitychange）は止めます。canvas の解像度は devicePixelRatio に合わせ、最大2倍までにします。

## 入れる演出（この5つだけ）
### A. ヒーローの登場「チューニング」（電波）
ページを開いたとき、一度だけ再生します。
- 名前「天音ルミ」を1文字ずつ span に分け、ラジオの周波数が合うように、少しぼやけた状態（filter: blur(6px)、opacity 0、横に数px ずれる）から、はっきりした状態へ順番に切り替えます。1文字 0.35 秒、間隔 0.08 秒程度。
- 続けて、キャッチコピーの3つの文節、紹介文、「次のライブ」、ボタンを、少しずつ遅らせて opacity と小さな上下移動（8px 以内）で表示します。全体で 1.6 秒以内に終えます。
- 名前の文字を span に分けても、読み上げでは「天音ルミ」と1語で読まれるようにします（h1 に aria-label="天音ルミ" を付け、文字の span は aria-hidden にするなど）。
- JavaScript が動かない場合は、最初から全部表示されていること（演出のための初期状態は、JS が html 要素にクラスを付けたときだけ適用する）。

### B. ヒーローの星空（星のまたたき）
- ヒーローの上に canvas を重ね、小さな星（40〜60個、半径 0.5〜1.5px）をランダムに置いて、ゆっくりまたたかせます（明るさの周期 3〜7 秒、星ごとにずらす）。色は --text と --ramune を混ぜる程度。
- 星は、ヒーロー画像のルミの顔や文字の上で目立たないよう、全体に控えめな明るさ（最大 opacity 0.7 程度）にします。
- 10〜18秒に1回、細い流れ星を1本だけ、0.8秒程度で斜めに流します。
- スマホ幅（720px 以下）では、ヒーローの画像部分の上にだけ描き、星の数を半分にします。

### C. 名前をタップすると、きらめく（星・可愛らしさ）
- ヒーローの名前「天音ルミ」をクリック・タップすると、押した位置から小さな星形（4〜5角の星、または十字のきらめき）が 8〜12 個はじけて、0.7 秒程度で消えます。色は --ramune、--lamp、--text を混ぜます。
- 名前はリンクやボタンではないので、カーソルは default のままでかまいません。ちょっとした遊び（イースターエッグ）として扱い、操作に必要な機能にはしません。
- 連打しても重くならないよう、同時に出る粒の上限（例: 60個）を決めます。B と同じ canvas を使ってもかまいません。

### D. ホログラムのグッズに光が走る（ホログラム）
- 「ホログラムアクリルスタンド」と「ランダム ホロカード」の2商品の画像だけ、マウスを乗せたとき（hover: hover の環境）とキーボードでフォーカスしたときに、ホログラムの反射のような光の帯が、画像の上を斜めに1回横切ります（0.9 秒程度）。
- 光の帯は、画像の上に重ねた疑似要素の linear-gradient（透明 → ラムネ色を薄く → 白を薄く → 透明）で表現します。素材（ホログラム）の質感の表現なので、グラデーションを使ってよい例外とします。mix-blend-mode: screen や soft-light で、画像になじませます。
- ほかの商品（ペンライト、Tシャツ）には付けません。画像の拡大もしません。
- 画像をフォーカスできるようにするには、商品全体を囲む要素に tabindex="0" を付けるのではなく、まず :hover だけで実装し、フォーカスは商品名など既存のフォーカス可能な要素があればそれを使います（なければ hover のみでよい）。

### E. 再生中の曲が「鳴っている」ことを見せる（電波）
- 試聴プレーヤーの「● 再生中」の丸を、実際の音に反応する小さなレベルメーター（縦棒5本、幅 3px、高さ最大 14px、色 --lamp）に置き換えます。
- Web Audio API の AnalyserNode で、再生中の audio の周波数データを読み取り、棒の高さに反映します（createMediaElementSource は audio 要素ごとに1回だけ作り、AudioContext は最初の再生操作のときに作る）。
- AnalyserNode が使えない環境や、データが取れない場合（file:// で開いた場合など）は、今の静止した「●」の表示のままにします。音が出なくなることは絶対に避けてください（createMediaElementSource の後は、必ず analyser を destination に接続する）。
- 一時停止中は棒を止めて、最小の高さにします。

## 演出の切り替え
- フッターの「ページの先頭へ」の近くに、「演出：オン」「演出：オフ」を切り替えるボタンを置きます（button 要素、aria-pressed で状態を表す、ラベルは「きらめき演出」など分かりやすく）。見た目は副ボタンと同じ控えめなものにします。
- オフにすると、B（星空）と C、D、E のアニメーションを止めます（E は静止した「●」に戻す）。設定は localStorage に保存し、次に開いたときも維持します。localStorage が使えない環境でもエラーにならないようにします（try/catch）。
- `prefers-reduced-motion: reduce` の環境では、初期状態をオフにします。

## 実装の場所

- CSS は css/style.css の末尾に「Effects（STEP3-3）」のセクションとしてまとめます。
