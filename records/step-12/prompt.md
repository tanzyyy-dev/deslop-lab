## 作業2: スマホ・タブレット・PC の見た目の総点検と調整

### レビュアーの指摘
タブレットで、ヒーロー画像が完全に文字の下に潜っている。スマホ・タブレット・PC の見た目を総点検して調整してほしい。

### 統括エージェントの点検結果（16の画面サイズで撮影・計測済み）
1. **タブレット縦（744〜1024px の縦長の画面）**: 画像に文字を重ねるレイアウトのまま、画像が大きく切り抜かれる。キャラクターの顔が、文字と濃い幕の下に隠れる（指摘の症状）。
2. **タブレット横・小さめの PC（1024×768、1180×820）**: 文字の列が、キャラクターの顔とマイクに重なる。画像が拡大されすぎて、顔が左に寄るため。
3. **1024〜1199px**: スケジュールとニュースの2段組（1024px 以上）では、スケジュールの列が狭すぎる。説明文が「オンライン配信 / 20:00 開始・（改行）無料」のように細切れに折り返される。
4. **楽曲のシングルの行**: ジャケット（96px）が、行の高さの中央に浮いて見える。文字の上端とそろっていない。
5. **スマホ 320px**: 「Fan Meeting「Good（改行）Night, …」」「光合成ラボ第（改行）3区」のように、言葉の途中で改行される。
（スマホの 320〜600px と、PC の 1366px 以上は、ヒーローを含めておおむね良好でした。）

### 調整の内容
1. **ヒーローのレイアウトの切り替え条件を変える**
   - 「画像に文字を重ねる」レイアウトは、**幅 1200px 以上、かつ横長の画面**（`(min-width: 1200px) and (orientation: landscape)`）のときだけにしてください。
   - それ以外（スマホ、タブレットの縦・横、1199px 以下）は、**画像を上、文字を下に分けるレイアウト**にします。
     - 720px 以下: 今のまま（画像は 4:3 の切り抜き）
     - 721px 以上: 画像の全体が見えるよう、元画像と同じ 16:9 で表示します（object-fit: cover で切り抜かない比率）。ただし高さが画面の 60% を超える場合は、max-height: 60svh にし、object-position で顔が切れないようにします。
     - 文字の列は、ほかのセクションと同じ左端（--gutter と --max の規則）にそろえ、幅は 36em 程度までにします。「次のライブ」の囲みとボタンは、文字の列の中に置きます。
   - 重ねるレイアウトで、文字の列とキャラクターの顔が重ならないようにしてください。元画像（images/hero-night.webp、1600×900）での顔の位置は、横 58〜78%、縦 15〜55% の範囲です。1200 / 1280 / 1366 / 1440 / 1920px の各幅で、表示上の顔の範囲を計算または計測して、文字の列の右端より 40px 以上右にあることを確かめてください。必要なら、ヒーローの高さ（例: 画像の比率に近い `min(88svh, 56.25vw)` を基本にし、文字が収まる最低限の高さを確保する）や object-position を調整します。
   - 演出（星空の canvas）は、レイアウトが変わっても画像の範囲に重なるようにしてください。
2. **最新の情報の2段組**: スケジュールとニュースを横に並べるのは、幅 1200px 以上にしてください。それ未満は縦に並べます。
3. **シングルの行**: ジャケットを、行の文字の上端にそろえてください（align-items: start）。
4. **言葉の途中での改行**: 次の箇所を、STEP 3-1 と同じ `<span class="phrase">` で文節に分けてください。
   - 「Fan Meeting」「「Good Night, Mira」」
   - プロフィールの出身「電脳都市」「ネオ・ミナト」「（光合成ラボ第3区）」
   - ほかにも、320px で単語や数字の途中で改行される箇所があれば、同じ方法で直してください。
